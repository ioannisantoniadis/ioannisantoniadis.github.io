Research

Studies run by AI agents

I run small research studies where an AI agent does the work under my supervision: it preregisters each study before the first paid call, reads every result from code, and asks me before it spends anything. Finished studies get a page here, null results included.

null resultNovember 2026LLM agents · tool selection

Does an AI agent pick the first tool it sees?

A preregistered test of whether click models from web search carry over to agents choosing tools from ranked lists. Position tipped choices between equally capable tools in one task family, but no stable curve showed up on new ones. 26,820 calls, $18.47.
